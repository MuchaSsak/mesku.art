# Architecture

Static multi-page site, Vite 6 + TypeScript + Tailwind v4, deployed on Vercel (prod: https://www.mesku.pl, apex mesku.pl 307→www; old domain mesku.art is dead/NXDOMAIN). No backend: Supabase was removed, images are static files.

## Layout
- `index.html` (O mnie / home), `moje-prace.html` (gallery), `kontakt.html`, `404.html` — Vite entries. Contain `<!-- site:head|nav|footer|carousel|gallery -->` placeholders.
- `plugins/site/` — Vite plugin rendering the pages at build/dev time:
  - `config.ts` — SITE_URL, ARTIST info, per-page title/description (keyed by html filename), nav links, eager image counts.
  - `templates.ts` — head (meta/OG/canonical/JSON-LD/font preload), nav (skip link, hamburger a11y), footer, carousel slides, gallery items, `renderImage` (eager | lazy w/ `sizes="auto, …"` | splide lazy w/ placeholder src), `splitHeadingChars` (h1 with `data-split-chars` → per-char spans + aria-label).
  - `seo.ts` — JSON-LD @graph (WebSite, Person, ProfilePage/CollectionPage+ImageGallery/ContactPage), image sitemap, robots.txt.
  - `index.ts` — plugin: transformIndexHtml(pre) + emits sitemap.xml/robots.txt (also served in dev).
- `src/data/artworks.ts` — hand-edited catalog: id, slug, title, medium (131 pieces) + `featuredArtworkEntries` (home carousel, `brighten` flag).
- `src/data/images.json` — GENERATED by `scripts/optimize-images.ts` (do not edit).
- `src/lib/` — `artworks.ts` (joins catalog+manifest, alt texts, MEDIUM_LABELS, findArtwork incl. legacy `{id}_{n}`), `imagePaths.ts` (file naming), `imageManifest.ts` (types), `navigation.ts` (hamburger), `carousel.ts` (Splide Polish i18n).
- `src/pages/` — `home.ts` (Splide loop autoWidth filmstrip, lazyLoad nearby), `gallery.ts` (single reusable `<dialog>`, Splide per art piece, `?zdjecie=<slug>` deep link with pushState/popstate), `common.ts` (kontakt + 404: nav only).
- `src/styles/main.css` — Tailwind + Splide CSS import + fonts (woff2 + metric fallback) + fixed bg pseudo-element + ALL entrance animations as CSS keyframes (GSAP removed).
- `src/assets/` — font woff2 (subset latin+ext), logo.svg (vector-traced from old png), background-1920/2859.webp.
- `public/` — `art/<slug>/*.webp` (generated), favicon.ico, apple-touch-icon.png, og-image.jpg.
- `vercel.json` — cleanUrls, no catch-all rewrite (real 404), immutable cache for /assets & /art, security headers + CSP (style-src needs 'unsafe-inline' for Splide <style> + inline --i / bg colors).

## Dependencies
runtime: @splidejs/splide. dev: vite, typescript, tailwind, sharp (image script), @types/node. Removed: splide-extension-grid (2026-10-23, carousel is an autoWidth filmstrip now), supabase-js, gsap, split-type, @types/masonry-layout. (TanStack Query was never in the repo.)
